## Overview

This repository contains the complete experimental code, data processing pipeline, and evaluation framework for the MSc thesis *"Multimodal Anomaly Detection for Dementia Remote Monitoring."*

The thesis investigates whether unsupervised anomaly detection can reliably identify clinician-verified alert days from retrospective, multimodal in-home sensor data (activity, sleep, physiology) in people living with dementia, using the [TIHM dataset](https://doi.org/10.1038/s41597-023-02519-y). Five anomaly-detection models are compared under a leakage-safe evaluation protocol:

| Model | Type | Description |
|---|---|---|
| **PCA** | Classical | Linear reconstruction baseline (90% variance rule) |
| **Isolation Forest** | Classical | Tree-based isolation scoring (100 estimators) |
| **LSTM-VAE** | Neural | Recurrent variational autoencoder (h=32, z=12) |
| **OmniAnomaly** | Neural | GRUCell recurrent-latent VAE (z_t conditioned on z_{t-1}) |
| **T-VAE (proposed)** | Neural | Modality-specific encoders + GCNConv fusion + Neural ODE |

### Key Finding

A **two-regime negative result**: architectural complexity does not outperform simpler baselines at this cohort's scale. PCA achieves the highest AUROC (0.710) in the primary evaluation, and training data volume — not model architecture — is the binding constraint on detection performance.

## Methodology

### Leakage-Safe Evaluation Protocol

The evaluation enforces four verifiable safeguards:

1. **Window-boundary leakage prevention** — chronological split performed *before* sliding-window generation
2. **Training-set contamination filtering** — any-event label excludes windows containing hidden alert days
3. **Deterministic scoring** — z = μ at evaluation (no latent noise)
4. **Training-only hyperparameter selection** — PCA k chosen by 90% training-variance rule

### Two-Fold Rolling-Origin Design

| | Training | Testing | n_train | n_test | Alerts |
|---|---|---|---|---|---|
| **Fold 1** | Block A | Block B | 44 | 93 | 6 |
| **Fold 2** | Block A+B | Block C | 111 | 101 | 7 |

### T-VAE Architecture

```
Input (B, 7, 22)
  → 3 modality LSTM encoders [8/8/6 features] (h=32 each)
  → T-GNN fusion (GCNConv × 2, Tanh)
  → Concatenate (dim=96)
  → Neural ODE (Euler, t∈[0,1], 2-layer MLP with Tanh)
  → Latent projection (μ, log σ², dim=12)
  → Reparameterize (z=μ at eval)
  → LSTM Decoder → Reconstruction (B, 7, 22)
  → Anomaly score = max per-day MSE
```

## Reproducing the Results

### Run the complete notebook

```bash
jupyter notebook notebooks/Final_Complete_Thesis.ipynb
```

The notebook is self-contained (41 cells) and runs sequentially from data loading through the final benchmark table and figures.

### Seed Control

All neural models are trained across **10 random seeds** (0-9). Reproducibility is ensured by:
- `torch.manual_seed(seed)`
- `torch.set_num_threads(1)`
- `torch.use_deterministic_algorithms(True)`

## Key Results

### Primary Result: Two-Fold Rolling-Origin Benchmark

| Model | Fold 1 AUROC | Fold 2 AUROC | Fold 2 AUPRC |
|---|---|---|---|
| **PCA** | 0.489 | **0.710** | **0.151** |
| LSTM-VAE | 0.450 ± 0.015 | 0.679 ± 0.008 | 0.165 ± 0.005 |
| OmniAnomaly | 0.440 ± 0.016 | 0.635 ± 0.018 | 0.111 ± 0.020 |
| T-VAE | 0.451 ± 0.017 | 0.678 ± 0.010 | 0.159 ± 0.005 |

### SHAP Feature Importance

`phys_heart_rate` is the #1 feature for both PCA (0.095) and T-VAE (0.359).
